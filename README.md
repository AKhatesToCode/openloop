# OPENLOOP

A social discovery application where conversations create persistent connection trails.

## Technology

* React + Vite + TypeScript
* Node.js + Express + TypeScript
* Local JSON-file persistence

## Project Status

MVP implementation in progress.

## Documentation

* `PROJECT_CONTEXT.md` — product scope, constraints, and implementation plan.
* `API.md` — shared frontend/backend API contract.

## Planned Core Features

* Discover and join discussion rooms.
* Save takeaways and questions.
* Follow topics.
* Create linked follow-up rooms.
* Explore saved conversation trails.
